# Community conduct

Be respectful and specific in issues, code reviews and project discussions. Critique code and driving behavior constructively. Welcome contributions from newcomers and people with different backgrounds, devices and access needs.

Harassment, threats, discriminatory remarks and publishing another person's private information are unacceptable. Use GitHub's reporting tools or contact a repository maintainer to raise a concern. Maintainers may moderate content and restrict participation to keep project spaces welcoming.
